# 終端姿勢の保持（2026-10-12）

対象症状は「指定した終わりの姿勢にならない／誤った姿勢で固定される」。[長尺モーションの指示追従](long-motion-fidelity.md)で残課題とした、区間の到達姿勢と次区間の部位固定のずれを扱う。

## 確認した原因

`tools/pose-arrival-audit.mjs`で、保存済みの計画と生成結果から各区間の中間・終端の腕の角度（0°=下ろす、90°=水平、180°=頭上）、体幹の前傾、腰の高さを測った。

| 症状 | 原因 |
| --- | --- |
| しゃがむと下ろした腕が前へ出て、そのまま保持される | 対象外の腕は胴体に対する関節角で固定される。体幹が前傾すると、下ろしていた腕（19〜35°）が55°前後へ振り上がる |
| 「両腕を下ろした立ち姿」の最後の6秒で腕が121°に上がっている | しゃがみ区間でARDYが腕を前へ出し（89°）、立ち上がり区間では腕が対象外。体幹が起きると腕も一緒に上がり、そのまま保持される |
| 跳躍直後の区間で5秒間宙に浮く（腰1.09〜1.16m） | 腰の上下を持たない区間は開始時の高さを保持する。区間が跳躍の途中から始まると空中の高さで固定される |

## 変更

すべてエンジン側の部位固定（`tools/ardy-engine/motion_scope.py`、`server.py`）と、計画の区間データの補足（`src/realtimePlan.js`）。モデル・推論ステップ・区間の接続方式は変更していない。

1. **下ろした腕は重力方向に垂れたまま保つ。** 区間開始時に下ろしていた（真下から45°以内）対象外の腕は、胴体の傾きに付いて行かず重力方向を保つ。胸の向き（ヨー）には追従するため、歩行・回転で腕が置き去りにならない。上げた腕は従来どおり胴体に対して固定する。手首が足首より下に入る場合は、その分だけ胴体固定側へ戻し、1フレームあたりの変化量を制限して滑らかにする。
2. **「腕を下ろした状態で終わる」区間は、まだ上がっている腕だけ生成する。** 区間の文章が腕を下ろした終端を要求し、その腕が対象外なら、計画は`lowerArms`を付ける。エンジンは区間開始時の実際の姿勢を見て、下ろせていない腕だけを生成対象に加える。すでに下りている腕は1.のとおり固定する。一律に腕を有効にすると、深いしゃがみでARDYが腕を前へ上げ直すため悪化した。
3. **空中から始まる区間は脚と腰の上下を生成対象に加える。** 足首・つま先がすべて、そのセッションで最も低かった足の位置より5cm以上上にある場合、腰の上下と両脚を加えて着地させる。前後左右の移動は固定のまま。腰の高さだけを床へ下ろす方式は、空中で曲げた膝のまま低くしゃがんだ姿勢を固定したので採用しなかった。

`ARDY_KEEP_HANGING=0`でエンジンを起動すると1.を無効にできる（比較・退避用）。

## 実測

保存済みのAstra計画（`long-motion-after`、`long-motion-30`）をシード42で再生成した。シードを固定してもARDYの出力は完全には再現しないため、変更後は2〜3回の範囲で示す。統計的な改善率の証明ではない。

| 指標 | 変更前 | 変更後 |
| --- | --- | --- |
| 30秒：最後の「両腕を下ろした立ち姿」の腕 | 121° / 122° | 19〜24° |
| 20秒：しゃがみ保持中の腕 | 46° / 49° | 25〜42° |
| 跳躍直後の手を振る区間の腰の高さ | 0.94m（別の回では1.09m・浮遊） | 0.93〜0.95m |
| 区間境界付近の腕の向きの最大角速度（しゃがみ開始） | 189°/秒 | 129〜174°/秒 |

最後のお辞儀が浅い・上体が戻る点、「上げた両手を振る」で腕の高さが生成ごとに揺れる点は、ARDYの生成内容によるもので今回の対象外。

## 再実行

```powershell
node tools/ardy-live-session-eval.mjs <出力フォルダー> --replay=<計画を保存したフォルダー> --only=astra-long-order,astra-long-celebration
node tools/pose-arrival-audit.mjs <出力フォルダー>
```

`--replay`は新しいAstra呼び出しを行わず、ARDY（:2337）だけを使う。`lowerArms`付きで比較する場合は、保存済み計画の各区間に`markLoweredArmTargets`を適用したフォルダーを使う。
